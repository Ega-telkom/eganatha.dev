## Proyek-proyek

### eganatha.dev
Situs statik portfolio ini. Dibangun menggunakan Hugo. Dikembangkan hanya untuk fungsionalitas dan tidak selebihnya, dengan aksesibilitas dan struktur semantik terpikirkan. [Repositori](https://github.com/Ega-telkom/eganatha.dev), [kunjungi](https://eganatha.dev)

### Biblio
Sebuah aplikasi e-book/perpustakaan. Frontend dikembangkan menggunakan Jetpack Compose, dan juga Laravel untuk bagian backend REST. Saya juga menerapkan spesifikasi [OpenAPI](https://www.openapis.org/) dalam bagian backend. [Repositori backend](https://github.com/Ega-telkom/biblio-backend), [repositori frontend](https://github.com/adzkya-fajri/Biblio)

### Fundivest
Sebuah permainan dalam laman situs tentang edukasi finansial. Backend dikembangkan menggunakan Go Fiber, PostgreSQL, Valkey, dan Gotenberg, dan juga Vite/Vue.js untuk bagian frontend. Proyek ini dibentuk untuk kompetisi *Fictpact* yang diadakan oleh Unikama. [Repositori backend](https://github.com/Ega-telkom/fundivest-backend), [repositori frontend](https://github.com/ALFADHANI284/FrontEnd)

### Jalurku
Sebuah laman situs tentang angket. Cara kerjanya yaitu dengan mengkurasi minat pengguna dalam survey menjadi jurusan sekolah. Backend dikembangkan menggunakan Go Fiber, PostgreSQL, dan Redis, dan juga Vite/Vue.js untuk bagian frontend. Proyek ini diadakan untuk kompetisi *Jagoan Hosting_ Infra Competition*. [Repositori backend](https://github.com/Ayam-Kampung/jalurku), [repositori frontend](https://github.com/Ayam-Kampung/Jalurku_FrontEnd)

### Smilebox
Sebuah laman situs tentang doktor gigi. Dikembangkan hanya menggunakan HTML, CSS, dan Javascript sederhana. Proyek ini membuatku juara 1 dalam kompetisi *UNIPRO Stage X* yang diadakan oleh Unikama. [Repositori](https://github.com/Ega-telkom/smilebox)

### Phostel
Laman situs tentang repositori foto. Dikembangkan menggunakan Flask. [Repositori](https://github.com/Ega-telkom/phostel)
