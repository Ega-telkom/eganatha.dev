## Projects

### eganatha.dev
This static portfolio site. Made using Hugo. Made to just work and nothing more, with accessibility and semantic structure in mind. [Repository](https://github.com/Ega-telkom/eganatha.dev), [visit](https://eganatha.dev)

### Biblio
An e-book/library app. Frontend is made using Jetpack Compose, as well as Laravel for the REST backend. From there I also learned the [OpenAPI](https://www.openapis.org/) spec. [Backend repository](https://github.com/Ega-telkom/biblio-backend), [frontend repository](https://github.com/adzkya-fajri/Biblio)

### Fundivest
A website game about fin-ed. Backend is made using Go Fiber, PostgreSQL, Valkey, and Gotenberg, as well as Vite/Vue.js for the frontend. This project is for *Fictpact* competition held at Unikama. [Backend repository](https://github.com/Ega-telkom/fundivest-backend), [frontend repository](https://github.com/ALFADHANI284/FrontEnd)

### Jalurku
A simple survey website. Works by curating the user's interests in the survey into a school major. Backend is made using Go Fiber, PostgreSQL, and Redis, as well as Vite/Vue.js for the frontend. This project is for *Jagoan Hosting_ Infra Competition*. [Backend repository](https://github.com/Ayam-Kampung/jalurku), [frontend repository](https://github.com/Ayam-Kampung/Jalurku_FrontEnd)

### Smilebox
A static website about dental. Made using simple HTML, CSS and Javascript. This project lead me in achieving 1st position in *UNIPRO Stage X* competition held at Unikama. [Repository](https://github.com/Ega-telkom/smilebox)

### Phostel
A simple photo repository website. Made using Flask. [Repository](https://github.com/Ega-telkom/phostel)
